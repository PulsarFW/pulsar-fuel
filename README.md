## Overview

Handles vehicle fuel consumption and gas station refueling. Doesn't register a `plsr.X` component — it's self-contained, not something other resources call into directly.

---

## Dependencies

- `pulsar_core` — framework core
- `pulsar_vehicles` — reads/writes the vehicle state fuel level is stored on
- `pulsar_pwnzor` — anti-cheat check loaded alongside every resource
